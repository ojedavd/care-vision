# External dependencies and private inputs

uv.lock pins Python packages. See THIRD_PARTY_NOTICES.md for upstream references.
Model weights, personal recordings, exact evaluation inputs and native COOL binaries
are external; none are committed to this repository.

The private evaluation bundle can contain identifiable original recordings. A blurred
presentation copy does not anonymize that bundle. The owner controls any separate
judge-only delivery and must establish its audience and permissions independently.
Repository access must not implicitly expose private local inputs or deployment keys.

The COOL SDK was preinstalled on the measured host. Marketplace entitlement,
provisioning on a blank host and exact native upstream revision remain documented
limitations. No SDK binaries or paid service configuration are supplied here.

No open-source license has been selected for CARE-Vision. Dependency/model/SDK
terms are separate. Do not infer a model asset's distribution rights solely from a
parent repository license, and do not copy third-party caches or datasets into Git.
